# Дальнейшая разработка

## Ближайшие три задачи

1. На основе проверенного Windows baseline добавить NodeSpec, сохранение
   черновых проектов и Session с типизированными командами/undo. Rust-проверки,
   шесть Scala-тестов и сквозные CSV/ML-примеры уже прошли; актуальные результаты
   находятся в VALIDATION.md. При рефакторинге сохранить эти сценарии.
2. Добавить train/test split с seed и обучаемую preprocessing pipeline:
   StringIndexer + OneHotEncoder. `fit` только на train, `transform` на test;
   сохранять preprocessing вместе с моделью. Проверить неизвестные категории,
   sparse vectors, соответствие коэффициентов исходным признакам.
3. Добавить desktop на eframe/egui: canvas, инспектор, загрузку/сохранение
   чернового графа и запуск preview через background job. Сначала выделить
   job handle с событиями, timeout и доступной во время выполнения отменой.

## После первой вертикали

- Сохранение и загрузка обученных моделей, явная политика перезаписи артефактов.
- Random Forest, Logistic Regression, GLM с проверенными метриками.
- Отбор признаков: современный DataFrame API и явно описанная статистика.
- Схема входов в инспекторе, отображение типов, обработка пропусков.
- Ограничение размеров отдельных значений preview и нагрузки worker.
- Проверки Windows/Linux и упаковка приложения с документированным JVM runtime.

Livy, удалённые кластеры и Spark Connect не входят в ближайший local-only этап.
Пользовательский Scala Script не переносится: исходное ограничение на выполнение
непроверенных скриптов сохраняется.
